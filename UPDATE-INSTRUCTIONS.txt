ANONDO BANGLA — GLOBAL EDITION UPDATE
=====================================

This is a complete root-level replacement package for the existing repository.
Repository: rayhanjavaengineer-dotcom/anondo-bangla
Branch: main
Hosting: existing Cloudflare Pages Git integration

UPLOAD
------
1. Extract this ZIP.
2. Upload/replace ALL files inside the extracted folder in the repository ROOT.
3. Do not upload the ZIP file itself. Do not delete existing repository settings.
4. Commit to main. Cloudflare Pages should deploy automatically.

FEATURES PRESERVED
------------------
- Original Anondo Bangla branding and creator credit.
- Bangladesh's existing 64-district dataset and Division Explorer.
- Existing profile name/photo, visited districts, theme and LocalStorage keys.
- Existing travel tools: Wishlist, Passport, Budget, Food Guide, Photo Gallery,
  Planner, Journal, QR Travel Card, Festival Calendar, Emergency info, Backup/Restore.
- Existing achievement card downloads, print, district details and PWA/offline shell.
- Premium Travel Identity profile integrated into the existing profile location.

GLOBAL FEATURES
---------------
- Global Country Explorer loads country names, flags, capital, region, currencies,
  languages and time zones from REST Countries v3.1 when online; a 7-day local cache
  supports previously loaded reference data offline.
- Currency Converter uses Frankfurter daily reference rates (no API key); rates are
  cached locally for up to 6 hours. The shown date is the provider's rate date.
- Rates are indicative reference rates, NOT bank cash/card/remittance buy-sell rates.

IMPORTANT LIMITATIONS
--------------------
This is still a static website. The Global Country Explorer is a country reference
directory; it does NOT yet provide verified subnational administrative boundaries
for every country, live hotels/restaurants/transport bookings, visas, emergency
contacts for every country, user accounts, cloud sync or server-side exchange-rate
history/charts. Those require additional verified datasets and/or a backend.
Currency and country data require an internet connection for first load and updates.

VALIDATION
----------
JavaScript syntax checks were run for the inline application script and all JS
assets. HTML structural checks, duplicate-ID checks, local asset references, 64
district record count and legacy storage-key checks were run on this package.
A live browser/Cloudflare deployment test is not possible from this ZIP build;
please wait for Cloudflare deployment Success before replacing an installed PWA.
