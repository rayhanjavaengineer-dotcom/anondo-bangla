ANONDO BANGLA — ULTIMATE INTERNATIONAL EDITION
==============================================

IMPORTANT: This ZIP is a complete root-level site update. Keep the existing
repository and Cloudflare Pages Git integration. Do not create a new project.

GITHUB REPOSITORY
-----------------
rayhanjavaengineer-dotcom/anondo-bangla
Branch: main

INSTALL
-------
1. Download and extract this ZIP on your computer.
2. Open the existing GitHub repository.
3. Upload/replace the files from this ZIP in the repository ROOT.
4. Keep every file in the ZIP. Do not upload the ZIP itself as the website.
5. Commit the changes to main.
6. Cloudflare Pages should automatically start a deployment from the connected
   GitHub repository. Wait until the deployment status is Success.

CLOUDFLARE PAGES SETTINGS
-------------------------
Framework preset: None (or existing setting)
Build command: leave empty
Build output directory: / (repository root)
Root directory: / (repository root)
Environment variables: none required for this static edition

Do not add Workers, D1, KV, or a custom domain for this release.
The included _headers file is read automatically by Cloudflare Pages.

AFTER DEPLOYMENT
----------------
1. Open the Cloudflare Pages production URL.
2. Test on both laptop and Android mobile browser.
3. If an installed PWA shows an old version, close all tabs of the site and
   reopen it. If necessary, uninstall and reinstall the PWA after confirming
   the new deployment is successful.

PRIVACY & DATA
--------------
Profile, visited districts, Wishlist, Budget, Gallery, Planner and Journal
are stored locally in the browser. They do not automatically synchronize
between devices. Use Data Backup & Restore to transfer personal data.
QR Travel Card calls a third-party QR image service only after the user checks
the consent box. The QR payload contains the chosen display name, visited
count and public website URL.

SCOPE NOTES
-----------
This is a static, local-first web app. Real user accounts, cloud sync, public
community uploads/reviews, live booking, live weather, live route distance,
and live hotel/transport prices require trusted live data sources and/or a
backend. They are not represented as working live services in this edition.
National fixed-date observances are shown; lunar festival dates must be
verified against official announcements each year.
