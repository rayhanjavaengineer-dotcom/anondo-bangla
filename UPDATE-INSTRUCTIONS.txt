ANONDO BANGLA — GLOBAL EDITION UPDATE
====================================

This is a complete replacement package for the existing Cloudflare Pages site.

UPLOAD
1. Extract the ZIP file.
2. Upload ALL files in this folder to the ROOT of the existing GitHub repository.
3. Replace files with matching names. Do not upload the ZIP itself.
4. Keep all assets in the repository root; do not move them into a subfolder.
5. Commit the changes. Cloudflare Pages should deploy from the connected main branch.

IMPORTANT PRESERVATION
- Original Anondo Bangla brand and Bangladesh 64-district dataset are retained.
- Existing LocalStorage keys and travel tools are retained.
- New navigation.js and navigation.css create a dedicated tool-view experience.
- global-tools.js uses countries.dev (keyless country data) and falls back to the older REST Countries endpoint; successfully loaded country data is cached locally.
- Currency conversion continues to use Frankfurter daily reference rates, not bank cash buy/sell rates.
- Service worker cache version is bumped to refresh updated files.

LANGUAGES
The interface language selector currently provides Bangla, English, Japanese, Chinese, Arabic, French, Spanish and Hindi for the main landing/dashboard navigation. Country names, native names and official languages are shown where supplied by the country dataset. This is a multilingual foundation, not yet a complete translation of every tool or every world language.

DATA LIMITS
The Bangladesh explorer and its 64-district achievement metrics remain Bangladesh-specific. The Global Country Explorer shows country-level reference data; it does not claim to provide every country's local administrative levels, visa rules, safety advice, hotels or live bookings. Verify travel-critical information with official sources.

TESTING
JavaScript syntax and package integrity are checked before release. After deployment, test the site on mobile and desktop, test the country search with Japan/Canada/Bangladesh, change interface language, open each tool from the dashboard, and test currency conversion.
