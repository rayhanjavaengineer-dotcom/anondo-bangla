ANONDO BANGLA — PREMIUM UPDATE v4
=================================

This is an add-on update. It does NOT replace your existing index.html,
district dataset, profile, visited tracker, achievement card, or theme logic.

FILES
-----
1. travel-tools.js
2. travel-tools.css
3. sw.js

GITHUB INSTALLATION
-------------------
A) Upload travel-tools.js and travel-tools.css to the ROOT of:
   rayhanjavaengineer-dotcom/anondo-bangla

B) Open the existing index.html on GitHub and click the pencil (Edit).
   In the <head>, immediately after the existing premium.css link, add:

   <link rel="stylesheet" href="travel-tools.css">

   Near the bottom, immediately before </body>, add:

   <script src="travel-tools.js"></script>

   Keep all existing code. Do not replace or delete the current HTML/JavaScript.

C) Replace the existing root sw.js with the sw.js file in this ZIP.
   This updates the offline cache to v4.

D) Commit changes to the main branch. Wait 1–3 minutes, then open:
   https://rayhanjavaengineer-dotcom.github.io/anondo-bangla/

E) If an older version remains visible, close the installed PWA/browser tab
   and reopen the site. The service worker should refresh the cache.

NEW FEATURES
------------
- My Travel Bucket List
- Digital Travel Passport stamps (synchronized with visited districts)
- Travel Budget Calculator (BDT)
- District Food Guide (uses the existing 64-district food information)
- Travel Photo Gallery (compressed photos stored locally in this browser)

IMPORTANT
---------
- Existing website name, creator credit, 64-district data and old features stay.
- New personal data is stored in this browser using localStorage.
- Gallery photos use browser storage, which is limited. Keep original photos
  separately and remove old gallery photos if browser storage becomes full.
- These features do not require a backend or paid API.
