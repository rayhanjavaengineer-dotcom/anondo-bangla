ANONDO BANGLA — RELEASE CANDIDATE STATUS
========================================

এই নথি প্যাকেজের বাস্তব scope ও যাচাইয়ের সীমা জানায়। অসম্পূর্ণ ফিচারকে সম্পূর্ণ বলা হয়নি।

এই প্যাকেজে অন্তর্ভুক্ত / উন্নত:
- Premium light/dark theme; Hero Box ও full-app background আলাদা; responsive CSS.
- Dedicated tool navigation; #tool-<key> deep-link, refresh এবং Back/Forward route restore.
- Global Country Explorer: country/territory name, capital, region, currency, language,
  calling code, timezone, area, population; search, region filter, sort, cache/retry.
- Global Travel Records: ব্যবহারকারী নিজে দেশ/স্থান/তারিখ/নোট যোগ, মুছতে ও local device-এ রাখতে পারবেন.
- Global country/place/points statistics: unique country ও unique country+place থেকে হিসাব;
  প্রতি unique place-এ ১০ points. একাধিক ভ্রমণ-তারিখ আলাদা record হতে পারে।
- Global records, expenses ও packing checklist backup/restore payload-এ অন্তর্ভুক্ত.
- Backup restore validation উন্নত: পুরোনো/আংশিক backup-এ অনুপস্থিত field থাকলে বর্তমান ডেটা অকারণে overwrite হবে না; restore ব্যর্থ হলে আগের local data ফিরিয়ে দেওয়ার চেষ্টা করা হয়.
- Profile, share text, QR summary-তে global metrics.
- Currency converter: From ও To উভয় currency selector-এর জন্য search; currency code/name
  এবং country mapping data পাওয়া গেলে country name দিয়ে filter; currency list cache/fallback ও Enter-to-convert.
- Weather/local time lookup: Open-Meteo geocoding + current weather; timezone display.
- City-to-city great-circle distance lookup; driving/flight route নয়.
- Global places search: countries.dev/GeoNames gazetteer; feature class/country filter,
  coordinates এবং Google Maps link.
- Destination/Hotel external Google Maps search shortcut; কোনো live hotel price/availability
  বা booking confirmation দেখানো হয় না.
- Travel Expense Tracker, Packing Checklist, existing planner/journal/gallery/wishlist/passport.
- PWA manifest, install helper, iOS Add to Home Screen guidance, Apple touch icon metadata,
  offline app shell/service-worker cache version.
- Existing Bangladesh 64-district data, original app features, original localStorage keys,
  original logo/icons/photos/assets retained from the supplied source package. No উপজেলা–ইউনিয়ন cascade is required or added for this global travel app.

তথ্যসূত্র / API:
- Country/city/place: countries.dev; underlying geographic place data via GeoNames (CC BY 4.0).
- Exchange reference rates: Frankfurter; daily reference data, not cash/bank buy-sell quote.
- Weather/geocoding: Open-Meteo; internet required, model/current data, not official emergency alerts.
- Maps and hotel discovery: Google Maps external search only.

V23 GLOBAL TOOLS CHANGE (১০ নভেম্বর ২০২৬)
1. District Food Guide → World Food Guide: country/cuisine area selection, live dish search, meal photos and recipe references. TheMealDB coverage is provider-limited; not every country's food is guaranteed.
2. Bangladesh Festival Calendar → World Festival & Holiday Calendar: country search, year selection, public holiday results from Nager.Date. Religious/cultural festivals outside its public-holiday dataset may be absent; lunar dates may change.
3. Travel Safety & Emergency: searchable country list, country-level general emergency number and tap-to-call. Data source is Wikipedia-derived and not officially verified; missing data is shown as unavailable, never guessed.
4. Travel Budget Calculator: international currency selector, four expense categories, live total, persistent private local browser storage. New budget is not sent to Firebase/Community. Same-device/browser access is not a secure account vault; manual backups can contain budget data.
5. Expense Tracker uses selected budget currency for new entries; older entries without currency remain BDT.
6. Service Worker cache bumped to v23-stage6-global-tools.
